# 우리고장 탐험대 · 29~32차시 수업PPT (공주·부여·논산·계룡)

연암대에서 이관된 25~32차시 가운데 **특산물 · 생활과 공동체** 담당분입니다.

| 파일 | 차시 | 슬라이드 |
| --- | --- | --- |
| `늘봄앵커_우리고장탐험대_29~30차시(공주부여논산계룡_특산물)_수업PPT.pptx` | 3회차(29~30차시) | 27장 |
| `늘봄앵커_우리고장탐험대_31~32차시(공주부여논산계룡_생활과공동체)_수업PPT.pptx` | 4회차(31~32차시) | 26장 |
| `deck_lib.js` / `gen_29_30.js` / `gen_31_32.js` | — | 생성 스크립트(내용 수정 후 재생성용) |

## 근거 자료

- **소주제**: `2026 앵커늘봄_우리고장 탐험놀이_유혜리, 유아현` 시트1 구성표 29~32행
- **슬라이드 체계**: 천안·아산 권역 확정본 `늘봄앵커(호서대)_우리고장 탐험대(5~6차시)_수업PPT`,
  `(7~8차시)_수업PPT`의 구성을 그대로 따름
  - 표지(권역 / 회차·부제 / 대상) → 목차(01~05 + 참고자료) → 학습목표(2개 + 관련 교과)
    → 동기유발 → 용어 풀이 → 활동 간지 → 「이렇게 해요」 ①~④ + `Q.` 핵심 발문
    → 학습정리(2개) → 차시예고 → 마무리
  - 활동 5개를 앞차시 3개 / 뒷차시 2개로 배분
  - 시간 배분: 도입 5분 / 활동 8·15·8분 / 정리 4분 (차시별)

## 29~30차시 (3회차) 고장의 자랑, 특산물 선물 꾸러미

| 활동 | 제목 | 차시·시간 |
| --- | --- | --- |
| 01 | 세 특산물을 살펴보아요 | 29차시 · 8분 |
| 02 | 소개 카드를 만들어요 | 29차시 · 15분 |
| 03 | 누구에게 어울릴까요 | 29차시 · 8분 |
| 04 | 선물 꾸러미의 조건을 정해요 | 30차시 · 8분 |
| 05 | 우리 모둠 선물 꾸러미 | 30차시 · 15분 |

- 용어 풀이: **특산물** / 보조 용어표: 제철 · 포장 · 택배
- 29차시에 만든 소개 카드를 30차시 꾸러미에 그대로 사용

## 31~32차시 (4회차) 함께 쓰는 마을 공간

| 활동 | 제목 | 차시·시간 |
| --- | --- | --- |
| 01 | 마을 공간 탐정이 되어요 | 31차시 · 8분 |
| 02 | 세대별 이용 지도를 만들어요 | 31차시 · 15분 |
| 03 | 같은 시간, 겹치는 바람 | 31차시 · 8분 |
| 04 | 이용자의 마음을 읽어요 | 32차시 · 8분 |
| 05 | 공동공간 이용표를 만들어요 | 32차시 · 15분 |

- 용어 풀이: **공동공간**
- 31차시 이용 지도에서 찾은 '겹치는 칸'이 32차시 이용표의 출발점
- 권역 마지막 회차이므로 차시예고 없음

## 수업 전 채워 넣을 곳

- **표지** 강사 / 보조강사 이름
- **29~30차시** 특산물 사진 (동기유발 1장 + 정보 카드 3장)
- **31~32차시** 마을 공간 사진 4장 (마을 도서관 · 다목적실 · 경로당 · 마을 운동장)

사진은 웹 검색 이미지 대신 **공공누리 자료 또는 직접 촬영·제작 자료**로 준비합니다.

## 교구재

기존 교구재 목록에 반영한 잠정 항목이 그대로 맞습니다.

- 29~30차시 — 공용 품목(색연필·가위·풀) + 5~6차시 모형돈 재사용
- 31~32차시 — **점착 메모지 또는 마스킹테이프** (활동 02·05에서 카드를 옮겨 붙여야 함)

## 알아 두실 점

슬라이드 **구성·문안·발표자 노트는 확정본 체계를 그대로 따랐지만, 시각 디자인(서식·색·레이아웃)은
기존 PPT 파일과 다릅니다.** 기존 파일을 내려받아 템플릿을 그대로 쓰려면 원본 .pptx가 필요합니다.
