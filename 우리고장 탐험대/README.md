## 산출물 종류

| 순서 | 산출물 | 상태 |
| --- | --- | --- |
| 1 | 회차별 교수학습과정안 (.hwp / HWPX) | 완료 — 4개 파일 |
| 2 | 수업용 PPT (.pptx) | 완료 — 8개 파일 |
| 3 | 활동지 · 해설지 | 예정 |

교수학습과정안은 천안·아산 5~8차시 원본과 **같은 HWPX 양식**(표 구조·문단 서식)을 그대로 씁니다.
`교수학습과정안_생성기/` 안에서 다시 만들 수 있습니다.

```
· 강사 안내   ▷ 학생 활동   ※ 유의점·수준별 지원   “파란 상자: 강사의 핵심 발문”
```

시간 배분은 회차마다 동일합니다.
사전준비 3′ / 목표안내 2′ / 흥미유발 5′ / 이론학습 10′ / 실습① 20′ / 실습② 30′ / 마무리 10′ = **80분**

## 공통 슬라이드 체계

천안·아산 권역 확정본(`우리고장 탐험대(5~6차시)_수업PPT`, `(7~8차시)_수업PPT`)을 그대로 따랐습니다.

표지(권역 / 회차·부제 / 대상) → 목차(01~05 + 참고자료) → 학습목표(2개 + 관련 교과)
→ 동기유발 → 용어 풀이 → 활동 간지 → 「이렇게 해요」 ①~④ + `Q.` 핵심 발문
→ 학습정리(2개) → 차시예고 → 마무리

- 활동 5개를 앞차시 3개 / 뒷차시 2개로 배분
- 시간 배분: 도입 5분 / 활동 8·15·8분 / 정리 4분 (차시별)
- 모든 슬라이드에 발표자 노트(지도 유의점) 수록
- 분량: 회차당 23~27장으로 맞춤

## 회차별 설계 요약

### 특산물 (4편)

| 차시 | 다루는 특산물 | 이 회차만의 축 | 산출물 |
| --- | --- | --- | --- |
| 13~14 | 마늘 · 쌀 · 꽃게 · 사과 (4종) | 나는 곳이 밭·논·바다·과수원으로 다름 | ‘오는 길’ 지도 |
| 21~22 | 한우 · 고추 · 김 · 한산모시 (4종) | 한산모시는 먹는 것이 아닌 **옷감** | 소개 문구 + 선물 |
| 29~30 | 알밤 · 멜론 (2종) | 보관 기간 차이가 선물 선택을 가름 | 선물 꾸러미 |
| 37~38 | 딸기 · 인삼 (2종) | 하나의 재료가 여러 모습으로(**가공**) | 쓰임 지도 + 선물 |

2종 권역은 깊이로, 4종 권역은 분류로 분량을 맞추었습니다.

### 생활과 공동체 (4편)

| 차시 | 다루는 장면 | 이 회차만의 축 | 산출물 |
| --- | --- | --- | --- |
| 15~16 | 농촌 · 어촌의 공동작업 | 때를 놓치면 안 되는 일 → **협동** | 마을길 이용 약속 |
| 23~24 | 읍내 · 농촌 · 바닷마을 이동 | 버스 네 번이라는 **제한 조건** | 마을버스 운행표 |
| 31~32 | 여러 세대가 쓰는 공동공간 | 겹치는 시간 → 시간·자리 나누기 | 공동공간 이용표 |
| 39~40 | 농촌 · 산지 마을의 도움 | 일마다 필요한 힘과 솜씨가 다름 | 역할 분담표 |

네 편 모두 **서로 다른 요구를 두 가지 이상 반영**하고, 이웃 모둠 의견을 받아
**한 가지만 수정**하는 보충 활동으로 마무리합니다.

## 수업 전 채워 넣을 곳

- **표지** 강사 / 보조강사 이름 (전 편 공통)
- **특산물 편** 특산물 사진 (동기유발 + 정보 카드)
- **생활과 공동체 편** 마을 공간 사진 3~4장

사진은 웹 검색 이미지 대신 **공공누리 자료 또는 직접 촬영·제작 자료**로 준비합니다.
