- **교수학습과정안** — 사전준비 3′ / 목표안내 2′ / 흥미유발 5′ / 이론학습 10′ /

- **활동지·해설지** — A4 세로 2쪽, 1쪽 01~03 · 2쪽 04~06, 주색 `F0813C`

## 아직 남은 일

### 1. 사진 31장

수업PPT의 점선 칸이 비어 있습니다. `6. 사진 준비` 폴더의 목록과 프롬프트를
쓰시면 됩니다. **서천 한산모시 한 장만 공공누리 자료**를 권합니다.

### 2. 강사·보조강사 이름

모든 수업PPT 표지가 비어 있습니다.

### 3. 글꼴

활동지·해설지는 **학교안심 지우개 R / 학교안심 알림장 OTF R**을 씁니다.
없는 컴퓨터에서 열면 다른 글꼴로 바뀝니다.

### 4. 시각 디자인

수업PPT의 구성·문안·발표자 노트는 확정본 체계를 따랐지만,
**서식·색·레이아웃은 기존 PPT 파일과 다릅니다.**
기존 파일을 템플릿으로 쓰려면 원본 .pptx가 필요합니다.

`_생성기` 폴더 안에서 내용만 고쳐 다시 뽑을 수 있습니다.

```bash

cd _생성기/교수학습과정안 && python make_13_16.py

# 수업PPT
cd _생성기/수업PPT && npm install pptxgenjs && node gen_13_14.js "출력.pptx"

# 활동지·해설지 (한 번에 16편)
cd _생성기/활동지 && npm install pptxgenjs && node build.js ./content_a.js
```
